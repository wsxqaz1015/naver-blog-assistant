# 경험 메모 양식 (초안 쓰기 전에 모으는 재료)
> 빠진 것만 하나씩 물어봐요. 메모하듯 짧게 답하면 돼요 (예: "일요일 6시 / 주차 가능 / 웨이팅 10분").
> 답은 초안 폴더 `facts.md`에 그대로 기록 → 글에는 여기 있는 내용만 써요.

## 1. 사진 체크 (빠진 종류가 있으면 알려주기)
- **맛집·카페**: 외관(간판) · 주차장 · 내부 전체 · 메뉴판(가격 보이게) · 주문한 메뉴 · 메뉴 가까이 · 편의시설
- **여행지**: 입구 · 운영시간/요금 안내판 · 내부 · 주요 볼거리 · 포토존 · 편의시설
- **제품**: 포장(앞·뒤 성분표) · 구성품 · 크기 비교 · 사용하는 모습 · 사용 전후
- 메뉴판 사진이 없으면 정확한 메뉴명·가격을 여쭤봄

## 2. 경험 메모
- 방문 요일·시간대 / 누구와 / 방문 계기
- 주차 / 웨이팅 / 붐빔 정도
- 주문한 메뉴 (메뉴판 그대로의 이름·가격)
- 가장 좋았던 것과 이유 / 아쉬웠던 점
- 공간에서 눈여겨본 디테일 (좌석·조명·창밖 등)
- 추천하고 싶은 사람 + 팁

## 3. 확인할 정보 (공식 홈페이지·공식 SNS 우선 → 네이버·카카오와 비교 → 다르면 알림)
| 맛집·카페 | 여행 | 제품 |
|---|---|---|
| 영업시간·휴무 | 운영시간 | 가격 |
| 주소 | 입장료 | 용량 |
| 주차 | 예약 방법 | 사용 방법 |
| 메뉴·가격 | 주차 | 특징 |
| 웨이팅·예약 | 이용 방법 | 보관 방법 |
