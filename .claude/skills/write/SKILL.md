# /write — 블로그 글 한 편 시작하기

**CLAUDE.md의 절대 규칙이 이 순서보다 항상 우선.** 발행은 절대 누르지 않음. 질문은 한 번에 하나씩, 쉬운 말로.
이 명령 자체가 글 작성 요청이므로, 브라우저 작업(임시저장·검증)은 사용자가 초안을 OK한 뒤에만 한다.
`blog-profile.md`의 '설치 상태'가 '완료'가 아니면 먼저 CLAUDE.md '처음 설치'를 진행한다.

1. **사진 확인**: `node src/photos.js` → 새 사진 중 이 주제에 쓸 사진을 사용자에게 확인. ⚠️ 표시(클라우드에서 안 받아짐 등)가 있으면 알림
2. **재료 모으기**: `prompts/경험메모-양식.md` 순서대로, 빠진 것만 하나씩 질문 → 초안 폴더 `facts.md`에 기록
   - 이미 `blog-profile.md`에 정한 것은 다시 묻지 않음
   - 가게 정보는 공식 홈페이지·SNS 우선, 다르면 알림. 확인 안 된 것은 쓰지 않음
3. **사진 준비**: 사진을 보고 사람 얼굴이 있으면 사용자에게 알리고 처리 방법을 물음 (`blog-profile.md` 12번 기준)
4. **초안 작성**: `drafts/<날짜-이름>/draft.md` (`blog-profile.md` 기준, 형식은 CLAUDE.md '초안 형식')
5. **검수 보고**: 초안과 함께 짧은 표로 — 글자 수, 소제목 수, 태그 수, 사진 수, `checkDraft`의 문제·경고(AI식 표현, 반복 감상 등)
6. 사용자가 **OK**하면 → `node src/approve.js <초안폴더>` → `node src/post.js <초안폴더> --dry-run` → `node src/post.js <초안폴더>`
7. 결과 보고: `result.md` 표 그대로, 실패 항목은 숨기지 않음. 마지막에 "발행은 직접 눌러주세요"

고칠 점을 말하면 초안을 고치고, 앞으로도 적용할 내용이면 `blog-profile.md`의 '고쳐가며 정한 것'에 저장.
