# 네이버 블로그 비서 (Claude Code용)

사진과 짧은 경험 메모만 주면 클로드가 내 말투로 네이버 블로그 초안을 쓰고,
내가 OK한 글만 **임시저장**한 뒤 다시 열어 원본과 똑같은지 확인해요.
**발행 버튼은 절대 누르지 않아요.** 발행은 내가 직접 읽어보고 눌러요.

## 사용법 (한 줄)

1. 바탕화면이나 문서 폴더에 **빈 폴더**를 하나 만들어요 (예: `블로그비서`)
2. Claude 데스크톱 앱 → **Code** 탭 → 그 폴더를 열어요
3. 아래 문장을 그대로 붙여넣어요

```
https://github.com/wsxqaz1015/naver-blog-assistant 을 이 폴더에 내려받아서 설치해줘. 깃허브 계정이 없으니 zip으로 받아줘. 받은 뒤에는 CLAUDE.md의 '처음 설치' 순서대로 진행해줘
```

그다음은 클로드가 하나씩 물어봐요. 네이버 로그인만 직접 하면 돼요.

## 준비물
- Claude Pro 이상 요금제 + Claude 데스크톱 앱 (Windows)
- 크롬 브라우저
- 본인 네이버 블로그 계정
- 사진을 PC 폴더로 가져올 방법 하나 (구글 드라이브·iCloud·OneDrive·네이버 MYBOX·케이블 중 아무거나)
- Node.js는 없으면 클로드가 설치를 도와줘요

## 이렇게 돌아가요
1. 사진을 사진 폴더에 넣고 `/write 주제` 입력
2. 클로드가 빠진 정보만 짧게 질문 (방문 시간, 메뉴, 가격, 느낀 점)
3. 초안 + 검수 보고표 (글자 수, 소제목, 태그, 어색한 표현)
4. 내가 읽고 고칠 점을 말하거나 OK
5. 네이버 임시저장 → 다시 열어 한 줄씩 비교 → 결과표 보고
6. 내가 임시저장함에서 확인하고 **직접 발행**

## 비서 가르치기
고칠 점을 말할 때 끝에 **"규칙에도 저장해줘"**를 붙이면 `blog-profile.md`에 쌓여서 다음 글부터 적용돼요.
처음에는 내 블로그에서 잘 된 글 2~3편 주소를 주면 말투와 구조를 분석해서 정리해줘요.

## 꼭 지켜주세요
- **발행은 사람이 직접.** AI가 쓴 글은 꼭 한 번 읽고 올려주세요.
- **본인 계정으로만, 하루 1~2건 정도만.** 브라우저 자동화는 네이버 약관상 회색지대예요.
- **비밀번호는 클로드에게 알려주지 마세요.** 로그인은 항상 직접.
- **`.naver-profile` 폴더(로그인 상태)는 절대 공유하지 마세요.**
- **없는 경험을 지어내게 하지 마세요.** 경험담은 내가 진짜 겪은 것만.
- 협찬 글은 맨 위에 협찬 표시를 꼭 넣어주세요.
